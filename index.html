📱 Recommended iPhone scanning method

  • Open the website in Safari.
  • Allow camera permission.
  • Start with the rear camera.
  • Slowly scan walls, ceilings, smoke detectors, clocks, chargers, mirrors, vents and other objects.
  • Try scanning with the room relatively dark.
  • If you see a persistent tiny bright point, physically inspect that location.
  • Use the Flip Camera button to compare the front and rear cameras.
  • The score is only a heuristic. Normal LEDs, reflections and lights can create false positives.
